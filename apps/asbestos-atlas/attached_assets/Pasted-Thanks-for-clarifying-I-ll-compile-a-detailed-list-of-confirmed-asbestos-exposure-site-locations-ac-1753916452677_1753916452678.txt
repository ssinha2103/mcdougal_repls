## Accessing Asbestos Site Data via Public APIs or Downloads

To programmatically access data on these asbestos sites, one can use **official EPA data services**. The EPA’s Envirofacts REST **API** provides direct access to Superfund site information from the SEMS (Superfund Enterprise Management System) database. For example, you can query the database for sites where a specific contaminant is present.

* **EPA Envirofacts API (Superfund SEMS data):** Using the RESTful interface, you can retrieve sites with asbestos listed as a contaminant. For instance, a query could be constructed as follows (returns JSON by default):

  ```bash
  curl "https://data.epa.gov/efservice/SEMS_ACTIVE_SITE/CONTAMINANT_NAME/ASBESTOS/JSON"
  ```

  In this example, `SEMS_ACTIVE_SITE` is the table of active Superfund sites, and the query filters where `CONTAMINANT_NAME` equals “ASBESTOS”, returning matching site records in JSON format. The API supports other formats (XML, CSV, etc.) by changing the URL suffix. This allows integration of up-to-date site data (including site name, location, NPL status, and contaminants) into web applications. *(Note: The exact table/field names may differ; see EPA’s Envirofacts API documentation for the Superfund schema. The “Contaminant of Concern” dataset is also available via EPA’s data services, which includes contaminants by media for NPL sites.)*

* **EPA Superfund Data Downloads:** If a direct API query is not feasible, the EPA provides downloadable datasets covering Superfund sites and contaminants. For example, the **“All Final NPL and Deleted NPL sites (FOIA 15)”** dataset contains information on all NPL sites nationwide, including the **contaminants of concern for each site**. This dataset (and others like it) can be obtained from EPA’s Superfund Data and Reports page on EPA.gov. One can download the data (often as Excel or CSV files) and filter for asbestos-related entries. Similarly, the ATSDR has published reports (PDFs and summaries) for the Libby vermiculite sites, which can be parsed or compiled into a dataset for use in applications.

**Recommendation:** For live programmatic access, the EPA’s Envirofacts API is preferred for its flexibility and direct querying of contaminants. The example `curl` command above demonstrates how a web application might retrieve all Superfund site records where “ASBESTOS” is listed, which would include the confirmed asbestos sites. In absence of an official ATSDR API, those site locations (from the Libby vermiculite investigations) can be integrated by downloading ATSDR’s public reports or data summaries and ingesting them into your application’s database. Always ensure the data is up-to-date and sourced from **official government databases** (EPA or ATSDR) for accuracy.
