Implementation Notes

On startup, if DB empty, load /data/*.seed.csv.

Nearest logic:

Filter hospitals where has_ld=1 when need=ld.

For need=nicu3 or need=nicu4, filter nicu_level >= requested level.

Compute distance with haversine; if OPENROUTESERVICE_API_KEY present, call ORS /v2/directions/driving-car to get real travel time. If the key is absent, show a tooltip “Travel times estimated without live routing.”

Detail page suggests a higher-level NICU if current hospital’s nicu_level is lower than requested.

Map markers:

Color by NICU level: gray(None), blue(II), orange(III), red(IV); add an “L&D” badge if has_ld=1.

Timeline: List closures (newest first) with date, facility name (linked to detail), service, and source URL.

CSV downloads: Stream from DB with proper Content-Disposition.

SEO:

<title>Ohio Maternity Care Access Map (2025) | L&D & NICU Levels</title>

<meta name="description" content="Search Ohio hospitals for Labor & Delivery and NICU levels. See closures since 2022 and estimate travel time from your ZIP. Download CSVs for reporting.">

Create clean slugs and canonical tags; add Open Graph tags with a static preview image.

Accessibility: Keyboard focus states, ARIA labels for filters, high-contrast marker legend.

Disclaimers: Prominent box—“Informational only, not medical advice; verify with your provider.”
